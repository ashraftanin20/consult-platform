# consult-platform
This project helps people in poor countries to get consultancy assistance from professionals who provide services volunteralry or with low fees. 
## Main Modules
1. User Module
   - User can sign up and loging as client or professional
2. Appointment Module
   - Professional can create free time slots for appointment
   - Client can reqeust an appointment
   - Prefessional can approve or cancel an appointment
3. Consultation Module
   - Professional can create consulation history
   - Client can read history
4. Recommendation Module
   - Professional can provide recommendations for client
   - Client recieve and follow the recommendation
...
